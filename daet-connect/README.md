# DAET Connect Bookings

Operator dashboard for Daet tourism bookings.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Features
- Filter by search, package, date, status
- Expandable booking cards
- Approve & Assign Eco-Guide modal with capacity verification
- Toast notifications

See `../IMPLEMENTATION_PLAN.md` for full spec.
