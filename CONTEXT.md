# Daet Connect

## Language

**Admin shell**:
The frame around every Tourism Office admin page: the sidebar, the top bar and, on phones, the header with its menu drawer.
_Avoid_: admin layout, admin chrome

**Sidebar**:
The admin shell's list of links to admin areas. It lists only areas that exist, and it collapses only when the admin presses its button.
_Avoid_: nav rail, side menu

**Top bar**:
The admin shell's bar across the top of the page, holding the section name and the account menu. It stays in place while the page scrolls.
_Avoid_: header (that word means the public site header)

**Admin area**:
One section of the admin, such as Fares or Reviews, reached from the sidebar.
