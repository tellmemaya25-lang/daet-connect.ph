Important system notes

  • Admin package review currently has no “Rejected” option. The diagram uses “Review / update package status,” not an Admin reject action.
  • A Tourist booking records the group size and lead contact; it does not collect each guest's name or age.
  • A Tourist ticket QR is available after full payment. It is different from the Guide's accreditation badge QR.
  • The Souvenirs page is a showcase/contact flow, not an in-app merchandise checkout.
  • Use test or redacted personal details, payment records, tickets, IDs, and locations in demos and screenshots.
