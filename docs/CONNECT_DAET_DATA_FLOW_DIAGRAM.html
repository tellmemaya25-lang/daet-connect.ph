Context Diagram — Level 0

One process represents the whole Daet-Connect System. External entities exchange data with it; the database detail is intentionally hidden at this level.

External entity Process Data store Arrow + label · Data flow
TouristSends account, booking, payment, and trip-planning data; receives package availability, booking status/ticket access, and itinerary results.
Tour Operator / Tour Guide / AdminSend package, application, approval, assignment, and check-in data; receive the status, roster, and reports needed for their roles.
External servicesPayMongo exchanges checkout and verified payment data. Gemini is optional; core trip planning can still return a rule-based plan without the model.

Detailed Data Flow Diagram — Level 1

The system is decomposed into six processes. D1–D7 are logical Supabase data stores; connectors are labeled with the information each process reads or writes.

External entity (square) Process (circle) Supabase data store (open-ended rectangle) Arrow + label · Data flow
2.0 Process Bookings → D3The tourist's selected package, date, guest count, and price option are validated; booking rows go to tours_bookings and participant rows to tours_booking_participants.
3.0 Generate AI ItineraryThe rule-based planner uses saved Daet attractions, fares, and published package data. Gemini can interpret or explain the request when available; the plan can still be generated without it. Plans are stored only when the tourist saves them.
4.0 Verify QR Check-inThe server checks the signed ticket, assigned guide/admin/operator permission, confirmed and fully paid booking, and tour date before the database records a check-in.
5.0 Process PaymentsPayMongo checkout and verified webhook events update the payment ledger. Operators can also review submitted manual payment receipts.
Data protection & notationSupabase Auth validates sessions; server authorization, row-level security, ownership checks, database constraints, and verified PayMongo webhooks protect reads and writes. D1*, D3*, and D3** repeat D1 or D3 for layout clarity; they are not extra tables.
